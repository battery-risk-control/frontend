# 시스템 아키텍처 개요

> 출처: 프로젝트_기획_정의서 v2 §5~6

## 레이어 구성

시스템은 프론트엔드(React 대시보드) / 게이트웨이(Nginx) / 백엔드 / 외부 연동 / 데이터 저장소의 5개 레이어로 구성된다.

- **백엔드 이중 트랙**: AI 로직(외부 데이터 수집, 리스크 분류 모델, RAG 브리핑 에이전트)은 FastAPI(Python), 안정성 중심 업무 로직(ERP 동기화, 사용자·권한 관리, 통계 집계 API)은 Spring Boot(Java). 두 서버는 별도 API 호출 없이 **동일 데이터 저장소를 공유**한다. FE는 화면에 따라 어느 서버의 엔드포인트를 호출하는지 구분해서 다뤄야 한다.
- **배포 환경**: 단일 EC2 인스턴스, Docker Compose로 서비스별 컨테이너화. Kubernetes 등 오케스트레이션 도구는 도입하지 않는다.

## ⚠️ 미확정 — 확인 필요

프로젝트 지식베이스에 아키텍처 다이어그램이 2종 있으며 서로 세부 구성이 다르다:

- `빅프로젝트_아키텍처_정의서.png`: 위 텍스트 설명과 대체로 일치 (React Dashboard / Spring Boot / FastAPI / AI Agent Layer / Docker / 외부 API·ERP·DB)
- `빅프로젝트_아키텍처_정의서_demo.png`: Apache Airflow, 사내 Vector DB, Multi-Agent Reasoning Layer(4단계 에이전트) 등 더 구체적인 컴포넌트를 포함

**어느 쪽이 확정판인지 아직 답변받지 못했습니다.** FE 입장에서는 API 게이트웨이 경로나 응답 구조가 달라질 수 있으므로, mock API 설계 전에 확인이 필요합니다.
