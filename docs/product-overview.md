# 프로젝트 개요 — 배터리 원자재 공급망 리스크 관제 AI 에이전트

> 출처: 프로젝트_기획_정의서 v2 (2026-07-10)

## 1. 프로젝트 개요

2차전지(배터리) 제조사의 구매팀을 대상으로, 리튬·코발트·니켈 등 핵심 원자재의 가격 변동과 지정학적 리스크를 상시 감지하고, 이를 사내 계약 조건 및 ERP 실적 데이터와 자동으로 대조하여 구매 담당자와 의사결정자가 신속하게 판단할 수 있도록 돕는 AI 기반 의사결정 지원 플랫폼이다.

## 2. 목표 고객 및 사용자 3계층

B2B, 2차전지 셀 제조사(예: LG에너지솔루션, 삼성SDI, SK온)의 구매팀 대상.

- **1계층 구매팀(실무)**: 리스크가 실제로 탐지·대응되는 현장. 원자재별 리스크 현황, 협력사별 의존도, 재고 소진 일수를 조회하고 내부 브리핑 자료를 참고해 협상·대응 수행.
- **2계층 경영기획팀**: 1계층에서 탐지된 개별 리스크를 집계해 전사 관점 패턴 파악. 사업부별 리스크 노출도 비교, 협력사별 리스크 이력 추이.
- **3계층 경영진**: 2계층 결과를 압축한 핵심 지표(KPI)로 최종 의사결정.

## 3. 핵심 원칙 (FE 구현 시 반드시 지킬 것)

- **비예측 원칙**: 시스템은 어떤 경우에도 미래 가격 추이나 리스크 확산 가능성을 예측하지 않는다. 화면 카피·문구에도 "예상", "전망" 등 예측성 표현을 넣지 않는다. (경영진 대시보드의 "예상 절감액"은 예외적으로 시뮬레이션 값임을 반드시 명시)
- **하이브리드 신뢰도 표시**: 모든 리스크 판단은 확정(계약·ERP 근거) / 참고(뉴스 기반) / 경고(검증 실패) 세 가지로 구분 표시한다. 이 라벨을 임의로 생략하거나 통합하지 않는다.
- **병기 원칙**: ERP 관점과 RAG(계약) 관점의 결과가 서로 다른 결론을 낼 수 있으며, 시스템이 하나로 통합하지 않고 나란히 제시한다. UI에서도 두 관점을 하나로 뭉뚱그리지 않는다.
- **내부 참고자료 한정**: 산출물(브리핑 카드, 보고서 등)은 협력사에 발송되는 대외 공식 문서가 아니라 내부 참고 자료다. "발송", "공문" 등의 표현을 쓰지 않는다.

## 4. MVP 범위

- **필수**: 1계층 구매팀 대시보드(리스크 현황판, 유형별 분포 차트), 로그인/회원가입, 신뢰도 라벨 표시
- **확장(시간 여유 시)**: 2·3계층 대시보드, 이메일/Slack 알림 연동
- **제외**: 실시간 스트리밍(MVP 단계에서는 데모용 정적 mock으로 구현, 배포 시점에는 실제 실시간 스트리밍 구현 예정), 자동 메일/메신저 발송, 완전 자동화된 대외 문서 발송, 가격 추이 예측
