## 원자재 가격 추이 — 화면 구성 후보 (2026-07-22 결정 보류)

결정: 2026-07-22, "전체보기" 탭 제거, "상세보기"(필터+요약카드+멀티라인) 단독 유지. 사유: (1) 원자재 드롭다운을 "전체"로 두면 전체보기와 내용이 중복됨, (2) surin 스타일 후보들보다 현재 상세보기가 더 낫다고 판단.

전제: 아래 두 후보는 모두 "컴팩트 뷰(전체보기에 해당) + 상세 뷰"라는 2단계 구조를 전제로 설계되었다. 지금 컴팩트 뷰(전체보기)가 삭제된 상태이므로, 이 후보를 재검토하려면 컴팩트 뷰에 해당하는 진입점을 다시 만들어야 한다.

(자재 탭 전환으로 하나씩 선택 + 큰 현재가 숫자 + 단일 계열 차트 + 기간 버튼 3M/6M/1Y/2Y + "상세 분석" 버튼으로 상세 뷰 진입)

## 공개 대시보드 좁은 화면 콘텐츠 신호 — 후보 (2026-07-23)

배경: 좁은 화면(760px 미만)에서 그리드가 2x2에서 1열 4행으로 전환되며 하단 콘텐츠 신호(ScrollHint, A안 — 하단 그라데이션+화살표)를 실험적으로 도입. 아래 두 대안은 검토했으나 이번 범위에서는 채택하지 않음.

- 도트 인디케이터 — 카드가 실제로 이름 붙은 독립 섹션으로 재구성될 때(점프 이동 가능할 때) 재검토. 지금처럼 단순 스크롤 구조에는 부적합하다고 판단(2026-07-23).
- 컷오프 기법 — 그리드를 뷰포트의 ~90% 높이로 배치해 다음 카드가 살짝 잘려 보이게 하는 방식. 화살표 없이도 스크롤 가능함을 암시할 수 있으나, 현재 grid-template-rows 구조 전체 재설계가 필요해 이번 실험 범위를 벗어난다. 전체 반응형 Phase에서 재검토.
