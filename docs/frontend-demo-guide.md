# 프론트엔드 단독(①단계) 시연 가이드

## 목적

이 문서는 `npm run dev`(mock 데이터, 백엔드 없이 단독 구동)로 전체 화면을 순서대로
시연하는 절차다. **이 문서는 mock 단독(①단계) 시연 절차만 다룬다** — 실 백엔드 연결
(②서비스 테스트 단계) 절차는 별도 문서 [docs/backend-integration-guide.md](backend-integration-guide.md)
를 참고한다(서비스별 실제 API가 다르므로 절차도 분리한다).

`npm run dev` 실행 후 `http://localhost:5173`에 접속하면 시작된다.

## 1. 비로그인 공개 대시보드 (`/`)

로그인 없이 진입하는 첫 화면. 상단에 3계층 탭(구매팀/경영기획팀/경영진)과 로그인/회원가입
버튼이 있고, 2x2 그리드로 4개 패널이 보인다:

1. **글로벌 리스크 관제 맵** — 이벤트뷰/국가뷰 토글, 마커 클릭 시 하단에 상세 리스트.
   마커에 마우스를 올리면(hover) 클릭 전까지 안 보이던 `confidence_label`(신뢰도 라벨)이
   라벨 아래 새 줄로 추가 표시된다(2026-07-27 신규, #3).
2. **AI 기반 권고 조치 리스트** — 등급 기반 일반 권고 문구.
3. **원자재 가격 추이** — 자재별 지수(기준일=100) 추이.
4. **실시간 뉴스 속보** — 최신순 정렬.

상단 탭을 클릭하면 로그인 상태가 없으므로 `/auth`로 이동한다.

## 2. 로그인 (`/auth`)

스플릿스크린 레이아웃, [시스템 로그인]/[권한 신청] 탭 토글.

**테스트 계정(mock 전용 — `src/api/auth.api.ts`의 `TEST_ACCOUNTS`, ③배포 전 삭제 대상)**:

| 이메일 | 비밀번호 | 계층 | 상태 |
|---|---|---|---|
| `purchasing@test.local` | `test1234!` | 구매팀(1계층) | APPROVED |
| `planning@test.local` | `test1234!` | 경영기획팀(2계층) | APPROVED |
| `executive@test.local` | `test1234!` | 경영진(3계층) | APPROVED |
| `pending@company.com` | 아무 값이나 | — | PENDING(승인 대기 락 화면 시연용) |

[권한 신청] 탭에서 새로 가입해도 mock은 항상 PENDING 응답을 반환한다(승인 대기 락 화면
경로를 로그인 없이도 확인 가능).

## 3. 1계층 구매팀 대시보드 (`/purchasing`, `purchasing@test.local`로 로그인)

좌측 사이드바(접기/펼치기 가능, `SideNavToggleButton`) + 단일 컬럼 본문 + 우측 알림 패널
구조. 본문 패널은 다음 순서로 등장한다:

1. **상단 KPI 요약** — 전체/심각/주의/정상 건수.
2. **원자재 리스크 요약** — 원자재 게이지 카드(더보기로 9장 상세 그리드 펼침/접힘) + 외부
   리스크 종합 점수 + ERP 영향 점수. 카드가 넘치면 좌우 화살표(스크롤힌트)가 나타나는데,
   **이 화살표를 클릭하면 "카드 1장 겹치는" 페이징 이동**도 된다(2026-07-27 신규, #6-1 —
   드래그/휠 스크롤과 별개로 클릭으로도 이동 가능).
3. **글로벌 리스크 관제 맵** — 공개 대시보드와 같은 위젯(구매팀 쪽은 `risk_event` mock
   기반, 공개 대시보드와 데이터 소스가 분리돼 있음).
4. **수입 의존도 + 원자재 가격 추이** — 2컬럼(940px 이하에서 1컬럼으로 자동 전환).
5. **원자재 공급사 리스크 현황** — 협력사별 리스크 등급·근거.
6. **ERP 영향** — 재고 소진일수·영향 자재.
7. **구매 대응 우선순위** — 대응 우선순위 리스트.

우측에는 **페이지 섹션 도트 인디케이터**가 있다 — 현재 보고 있는 섹션의 도트가 활성
표시되고 클릭하면 해당 섹션으로 스크롤 이동한다. **도트에 마우스를 올리면 섹션 제목이
알약형 배지로 뜨고(1단계), 그 배지에 마우스를 더 올리면 8개 섹션 전체 목록으로
확장된다(2단계)**(2026-07-27 신규, #1).

**우측 알림 패널("주요 알림 및 빠른 작업")**은 등급 '심각' 또는 신뢰도 '경고'인 항목을
우선 노출한다. 헤더(계정 정보-로그아웃 사이)의 벨 아이콘을 클릭하면 패널을 접거나 펼칠
수 있고, **접힌 상태에서 벨 아이콘에 마우스를 올리면 상위 4개 미리보기가 잠깐 뜨며, 그
상태에서 클릭하면 펼침 상태로 고정**된다(2026-07-27 신규, #7). 배지 숫자는 패널 상태와
무관하게 항상 표시된다. 펼침/접힘 상태는 다른 화면(브리핑 상세 등)으로 이동했다 돌아와도
유지된다.

각 리스크 항목의 "브리핑 보기" 링크를 클릭하면 `/purchasing/briefing/{risk_event_id}`로
이동해 계약조항 요약·협상 포인트를 볼 수 있다(뒤로가기로 복귀).

## 4. 2계층 경영기획팀 대시보드 (`/planning`, `planning@test.local`로 로그인)

사업부별 리스크 노출도 비교, 협력사별 리스크 이력 추이 집계 화면.

## 5. 3계층 경영진 대시보드 (`/executive`, `executive@test.local`로 로그인)

누적 리스크 탐지 KPI, 예상 절감 시뮬레이션(반드시 "시뮬레이션" 라벨과 함께 표시 —
비예측 원칙의 유일한 예외), 사업부별 리스크 노출도 요약.

## 참고

- 상단 탭/홈 아이콘으로 언제든 화면 간 이동 가능. 계층이 다른 화면에 진입하려 하면
  확인 모달("내 화면으로 이동"/"취소")이 뜬다.
- 로그아웃은 Header 우측 버튼 — 인증 상태는 메모리 전용이라 새로고침하면 사라진다.
- 실 API로 이 화면들을 연결해서 보고 싶다면(예: 공개 대시보드 지도가 실 데이터로 뜨는지)
  이 문서가 아니라 [docs/backend-integration-guide.md](backend-integration-guide.md)를
  따라 `npm run dev:live`로 전환한다.
